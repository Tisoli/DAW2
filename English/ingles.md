### GET MORE TECHNICAL — Virtual machines

A **virtual machine (VM)** is a computer system created using software that runs inside a real physical computer. It works like an independent computer, even though it does not exist as physical hardware.

The real computer is called the **host machine**. Inside it, special software called a **hypervisor** creates and manages one or more virtual machines. The hypervisor controls how system resources are shared, such as CPU, RAM and storage.

Each virtual machine behaves like a complete computer. It has its own operating system, its own applications and its own virtual environment. For example, one VM can run Windows while another runs Linux, all on the same physical machine.

Virtual machines are isolated from each other. This means that if one VM fails or has a problem, the other virtual machines and the host system are not usually affected. This feature is called **isolation**.

One of the main uses of virtual machines is software development. Developers use them to test programs in different systems without changing their main computer. They are also widely used in cybersecurity, where suspicious files can be analysed safely inside a controlled environment.

However, virtual machines also have some limitations. Since they share the resources of the host computer, their performance is usually lower than that of a physical machine.

**1. Read the rules.**

**PAST SIMPLE**
- Actions completed at a specific time in the past.
  - *I installed a new program yesterday.*
- Past facts and habits.
  - *She was very good at maths when she was a child.*

**PAST CONTINUOUS**
- Actions that were in progress at a specific time in the past.
  - *We were coding yesterday at 7 p.m.*
- An unfinished action interrupted by another action.
  - *We were coding when the computer crashed.*
