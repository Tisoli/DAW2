## 1. Vocabulary — Unit 1: Information Technology

### 1.1 Types of computers

| Type | What it is |
|---|---|
| **desktop** | a computer for a fixed place (home or office) |
| **laptop** | a portable computer with a screen, keyboard and battery |
| **smartphone** | a small portable computer with a touchscreen and apps |
| **workstation** | a powerful desktop for professional work (3D design, video editing) |
| **server** | a computer that stores data and provides services to many users on a network |
| **mainframe** | a very large, powerful computer that processes millions of transactions |
| **supercomputer** | an extremely fast computer for complex calculations and simulations |
| **embedded system** | a small computer built inside another device (traffic lights, washing machines) |
| **wearable computer** | a device worn on the body (smartwatch, fitness band) |

**Remember:** a computer needs a **CPU**, **memory**, **storage**, **input/output** devices and **software** to work.

### 1.2 Peripherals

- **Input:** keyboard, mouse, barcode scanner, webcam, fingerprint reader, graphics tablet, microphone.
- **Output:** monitor, printer, projector, speakers.
- **Storage:** USB flash drive, external hard drive, memory cards.
- **Other:** power adapter, USB hub.
- **Both input and output:** headset (microphone + headphones), VR headset.

### 1.3 Inside the computer

| Part | Function |
|---|---|
| **CPU** (processor) | carries out instructions; the "brain" of the computer |
| **RAM** | temporary memory; stores data while the computer is working |
| **SSD / HDD** | long-term storage; SSDs have no moving parts, so they are faster, quieter and more reliable |
| **GPU** | processes images, video and graphics (gaming, video editing, AI) |
| **motherboard** | the main circuit board; connects the CPU, memory, storage and other parts |
| **cooling system** | heat sink and fans (or liquid cooling) to prevent overheating |
| **expansion slots and ports** | connect internal components and external devices |

### 1.4 Key verbs and adjectives from the reading

| Word | Meaning |
|---|---|
| **store** | keep / save data |
| **process** | work with information |
| **run** | (a program) operate |
| **allow** | make possible |
| **improve** | make something better |
| **connect** | join together |
| **upgrade** | make a computer more powerful |
| **temporary / permanent** | for a short time / forever |
| **reliable** | works well without problems |
| **complex** | not simple |
| **capable of** | able to |
| **responsible for** | in charge of |
| **at once / simultaneously** | at the same time |

## 2. Grammar — Present simple vs present continuous

| | Present simple | Present continuous |
|---|---|---|
| **Form** | verb / verb + -s | am / is / are + verb + -ing |
| **Use** | facts, routines, habits | actions happening now, temporary situations, future arrangements |
| **Examples** | A monitor **displays** information. / He **works** as a technician. | She **is installing** a new system. / We **are meeting** clients tomorrow. |
| **Signal words** | usually, often, every day, once a week | now, at the moment, today, this week, next Monday |

**Stative verbs** (usually not continuous): want, like, know, need, understand.
- ✔ The user **knows** the password.
- ✘ The user is knowing the password.

**Questions:**
- **Do / Does** + subject + verb? → *Does your laptop need an upgrade?*
- **Wh- + do / does** + subject + verb? → *Where does Mike print his documents?*
- **Be + subject + -ing?** → *Is the network working properly at the moment?*

## 3. Vocabulary and grammar — Unit 2: Programming

### 3.1 What is a programming language?

A programming language is a set of **rules** used to instruct a computer to perform specific **tasks**. Each language has its own keywords and **syntax**. Languages allow **programmers** to write **code** that controls how a computer works. Low-level languages give more direct control over the **hardware**, but they are harder to learn.

### 3.2 Programming languages

| Language | Used for |
|---|---|
| **JavaScript** | interactive websites (buttons, animations) |
| **PHP** | dynamic web pages on servers |
| **Java** | programs that run on many different computers |
| **Python** | web development, data science, automation; easy to learn |
| **SQL** | storing, searching and organising information in databases |
| **C++** | programs that need speed or control (games, system software) |

### 3.3 Software development: the stages

**design** → **test** → **release** → **deploy** → **update** · **add** (features) · **fix** (problems)

### 3.4 Bugs

| Word | Meaning |
|---|---|
| **patch** | a small update that fixes problems or improves security |
| **glitch** | a small or temporary problem |
| **crash** | a sudden failure that stops the program |
| **debugging** | finding and fixing problems in a program |

### 3.5 Roles

- **programmer** — writes code
- **developer** — builds software, plans features, tests and maintains applications
- **front-end developer** — works on the part of a website that users see
- **back-end developer** — works on databases and server logic
- **full-stack developer** — works on both front-end and back-end
- **QA tester** — tests software to find problems

### 3.6 Reading: why Python is popular

1. **Clear syntax** — it looks almost like English.
2. **Libraries** — Pandas, NumPy and TensorFlow save time.
3. **Community** — millions of programmers share tutorials and advice.
4. **Versatile** — it runs on Windows, Mac, Linux and small devices like the Raspberry Pi.
5. **Used by big companies** — Google, Netflix and Instagram.

### 3.7 Past simple vs past continuous

| | Past simple | Past continuous |
|---|---|---|
| **Form** | verb + -ed / irregular | was / were + verb + -ing |
| **Use** | finished actions; past facts and habits | actions in progress; unfinished action interrupted by another |
| **Examples** | She **created** the first algorithm. | We **were coding** when the computer **crashed**. |

**Time linkers:** while, when, suddenly, ago, last night.
- **While** she **was reviewing** the code, she **found** a bug.

## 4. Writing — a for and against essay

**Structure (4 paragraphs):**
1. **Introduction** — present the topic: *"…is growing fast these days, and more and more people use it."*
2. **Advantages** — *"On the one hand, … For example, … In addition, …"*
3. **Disadvantages** — *"On the other hand, … One major concern is that… Another problem is that… Moreover, …"*
4. **Conclusion** — *"To sum up, … Therefore, it is important to…"*

**Linking words**

| Function | Expressions |
|---|---|
| introducing | nowadays, these days |
| adding | in addition, moreover, also |
| contrasting | on the other hand, however |
| giving examples | for example, for instance |
| concluding | to sum up, in conclusion, therefore |

## 5. Speaking — useful phrases

**Recommending solutions:** We highly recommend… · A suitable solution would be… · In your case, we suggest using… · The best option would be… · It might be a good idea to…

**Understanding a problem:** What exactly happens when the problem occurs? · What were you doing when it happened? · Does it happen all the time or only sometimes?

**Explaining a cause:** It might be caused by… · This could be due to… · It seems to be related to…

**Proposing a solution:** You should try… · I recommend… · You may need to… · If that doesn't work, we can…

**Giving advice:** You should… · Why don't you…? · It's a good idea to… · If I were you, I would…

## 6. Virtual machines (page 15)

- A **virtual machine (VM)** is a computer created by software inside a real computer.
- The real computer is the **host**; the software that creates and manages VMs is the **hypervisor**.
- VMs share the host's **resources** (CPU, RAM, storage).
- **Isolation** means one VM's problems do not affect the others.
- Uses: software development, testing, cybersecurity.
- Limitation: lower performance than a physical machine.

- [ ] I can explain the function of the CPU, RAM, SSD, GPU and motherboard.

- [ ] I can form questions with do / does and with be + -ing.
- [ ] I can describe the stages of software development.
- [ ] I can explain the difference between front-end, back-end and full-stack.
- [ ] I can use the past simple and past continuous with while / when.

**Common mistakes to avoid:**
- third person singular: *He **works*** (not *He work*)
- questions: *Does he work?* (not *Does he works?*)
- stative verbs: *I **know*** (not *I am knowing*)
- past continuous needs *was/were*: *We **were running** the program when it crashed.*

## 2. 语法：一般现在时 vs 现在进行时

| | 一般现在时 | 现在进行时 |
|---|---|---|
| **构成** | 动词原形 / 第三人称单数 + s | am / is / are + 动词-ing |
| **用法** | 事实、习惯、日常动作 | 此刻正在发生、临时情况、将来的安排 |
| **例句** | A monitor **displays** information. 显示器显示信息。 | She **is installing** a new system. 她正在安装新系统。 |
| **标志词** | usually, often, every day, once a week | now, at the moment, today, this week, next Monday |

**状态动词**（一般不用进行时）：want, like, know, need, understand。
- ✔ The user **knows** the password. 用户知道密码。
- ✘ The user is knowing the password.

**疑问句：**
- **Do / Does** + 主语 + 动词原形？→ *Does your laptop need an upgrade?* 你的笔记本需要升级吗？
- **疑问词 + do / does** + 主语 + 动词原形？→ *Where does Mike print his documents?* Mike 在哪里打印文件？
- **Be + 主语 + 动词-ing？**→ *Is the network working properly at the moment?* 网络现在运行正常吗？

## 3. 第二单元词汇与语法：编程

### 3.1 什么是编程语言

编程语言是一套**规则（rules）**，用来指示计算机完成特定的**任务（tasks）**。每种语言都有自己的关键字和**语法（syntax）**。编程语言让**程序员（programmers）**编写**代码（code）**，控制计算机和软件的行为。低级语言能更直接地控制**硬件（hardware）**，但更难学。

### 3.2 编程语言

| 语言 | 用途 |
|---|---|
| **JavaScript** | 让网站有交互（按钮、动画） |
| **PHP** | 服务器端的动态网页 |
| **Java** | 能在多种不同计算机上运行的程序 |
| **Python** | 网页开发、数据科学、自动化；容易学 |
| **SQL** | 在数据库中存储、查询和整理信息 |
| **C++** | 需要速度或底层控制的程序（游戏、系统软件） |

### 3.3 软件开发的阶段

**design 设计** → **test 测试** → **release 发布** → **deploy 部署** → **update 更新** · **add 添加**（功能） · **fix 修复**（问题）

### 3.4 程序错误（bugs）

| 单词 | 意思 |
|---|---|
| **patch** 补丁 | 修复问题或提升安全性的小更新 |
| **glitch** 小故障 | 小的或暂时的问题 |
| **crash** 崩溃 | 程序或系统突然停止工作 |
| **debugging** 调试 | 查找并修复程序中的问题 |

### 3.5 职位

- **programmer** 程序员 —— 写代码
- **developer** 开发者 —— 构建软件、规划功能、测试和维护
- **front-end developer** 前端开发 —— 负责用户看到的部分
- **back-end developer** 后端开发 —— 负责数据库和服务器逻辑
- **full-stack developer** 全栈开发 —— 前后端都做
- **QA tester** 测试员 —— 测试软件、找出问题

### 3.6 阅读：Python 为什么流行

1. **语法清晰** —— 看起来几乎像英语。
2. **库（libraries）** —— Pandas、NumPy、TensorFlow 能节省时间。
3. **社区（community）** —— 数百万程序员分享教程和建议。
4. **多平台（versatile）** —— 能在 Windows、Mac、Linux 和树莓派等小设备上运行。
5. **大公司使用** —— Google、Netflix、Instagram。

### 3.7 一般过去时 vs 过去进行时

| | 一般过去时 | 过去进行时 |
|---|---|---|
| **构成** | 动词 + ed / 不规则动词 | was / were + 动词-ing |
| **用法** | 已完成的动作；过去的事实和习惯 | 过去正在进行的动作；被另一动作打断的未完成动作 |
| **例句** | She **created** the first algorithm. 她创造了第一个算法。 | We **were coding** when the computer **crashed**. 电脑崩溃时我们正在写代码。 |

**时间连接词：** while, when, suddenly, ago, last night。
- **While** she **was reviewing** the code, she **found** a bug. 她审查代码时发现了一个 bug。

## 4. 写作：利弊类作文（for and against essay）

## 6. 虚拟机（第 15 页）

- **虚拟机（VM）** 是用软件在真实计算机内部创建出来的计算机。
- 真实的计算机叫 **host（主机）**；创建和管理虚拟机的软件叫 **hypervisor（虚拟机管理程序）**。
- 虚拟机共享主机的**资源（resources）**：CPU、内存、存储。
- **隔离（isolation）** 指一台虚拟机出问题通常不影响其它虚拟机和主机。
- 用途：软件开发、测试、网络安全。
- 缺点：性能通常低于物理机。
