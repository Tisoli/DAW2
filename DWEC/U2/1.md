# Tema 2. Introducción a la programación en JavaScript

## 1. JavaScript como lenguaje de programación del lado cliente

JavaScript es el principal lenguaje de programación utilizado en el lado cliente de las aplicaciones web. Se ejecuta habitualmente en el navegador y permite añadir lógica, interactividad y comportamiento dinámico a las páginas.

Entre sus principales posibilidades se encuentran la manipulación del contenido de una página, la respuesta a eventos del usuario, la validación de formularios, la comunicación con servidores y el acceso a distintas APIs proporcionadas por el navegador.

JavaScript está soportado por los principales navegadores web y se integra directamente con HTML y CSS, por lo que constituye una de las tecnologías fundamentales del desarrollo web en el lado cliente.

Por estas características, JavaScript es el lenguaje utilizado en este módulo para desarrollar programas que se ejecutan en el navegador.

### ¿Por qué se utiliza JavaScript como lenguaje de programación del lado cliente?

JavaScript es adecuado para la programación del lado cliente porque:

- Está soportado por los principales navegadores web;
- Se integra directamente con HTML y CSS;
- Permite manipular el contenido de una página web;
- Permite responder a eventos del usuario;
- Permite validar formularios;
- Permite comunicarse con servidores;
- Permite acceder a las APIs proporcionadas por el navegador.

## 2. Fundamentos de JavaScript

El código JavaScript se incluye en una página web mediante la etiqueta `<script>`. Puede escribirse directamente dentro del documento HTML o almacenarse en un archivo externo.

### 2.1. Inclusión de JavaScript en una página web

Utilizando la etiqueta `<script>`. El código JavaScript puede estar directamente en el documento HTML o en un archivo aparte.

Directamente dentro del HTML:

```html
<script>
    // Código JavaScript
</script>
```

Es conveniente que el código JavaScript esté dentro del "body" y al final, ya que así se garantiza que todos los elementos del documento HTML han sido creados por el navegador cuando empieza a ejecutarse el código JavaScript.

En un archivo aparte:

```html
<script src="ruta/nombreArchivo.js"></script>
```

Los archivos que contienen código JavaScript se guardan normalmente con la extensión `.js`. Esta extensión permite identificar el archivo como código JavaScript y facilita que editores, servidores y otras herramientas lo traten correctamente.

### 2.2. Sentencias

Una sentencia es una instrucción que realiza una determinada acción dentro de un programa.

En JavaScript no siempre es obligatorio finalizar las sentencias con punto y coma (`;`), ya que el lenguaje dispone de un mecanismo denominado **Automatic Semicolon Insertion (ASI)**, que puede insertar automáticamente el punto y coma en determinados casos.

Sin embargo, es recomendable escribirlo explícitamente para evitar ambigüedades y facilitar la lectura del código.

> En este módulo será obligatorio finalizar las sentencias con punto y coma (`;`).

### 2.3. Bloques

Un bloque es un conjunto de sentencias agrupadas entre llaves `{ }`.

Los bloques se utilizan, entre otros casos, en estructuras de control, bucles y funciones.

Por ejemplo:

```js
{
    let numero = 10;
    console.log(numero);
}
```

### 2.4. Identificadores

Los identificadores son los nombres que se utilizan para referirse a variables, constantes, funciones, clases y otros elementos del programa.

Para crear un identificador válido deben cumplirse las siguientes reglas:

- El primer carácter debe ser una letra, un guion bajo (`_`) o un signo de dólar (`$`).
- Los caracteres siguientes pueden ser letras, números, guiones bajos (`_`) o signos de dólar (`$`).
- No pueden utilizarse palabras reservadas del lenguaje como `let`, `const`, `function`, `class`, `if`, `else`, `while` o `return`, entre otras.
- JavaScript distingue entre mayúsculas y minúsculas.

Por tanto, los identificadores `nombre`, `Nombre` y `NOMBRE` se consideran diferentes.

### 2.5. Comentarios

Los comentarios permiten añadir anotaciones al código que no son ejecutadas por el motor de JavaScript.

Para comentar una sola línea se utilizan dos barras:

```js
// Esto es un comentario de una línea
```

Para comentar varias líneas se utilizan `/*` y `*/`:

```js
/*
    Esto es un comentario
    de varias líneas.
*/
```

## 3. Variables y constantes

Los programas necesitan almacenar datos para poder utilizarlos durante su ejecución. En JavaScript estos datos pueden asociarse a identificadores mediante variables y constantes.

Las variables permiten que el valor asociado pueda cambiar durante la ejecución del programa, mientras que las constantes no permiten reasignar un nuevo valor una vez declaradas.

### 3.1. Ámbito de variables y constantes

El ámbito de una variable o constante determina en qué parte del código puede ser utilizada. Dependiendo del lugar en el que se declare, una variable o constante podrá estar disponible en todo el programa o únicamente dentro de una parte concreta del mismo.

Básicamente existen dos tipos de ámbito: el **global** y el **local**.

**Ámbito global**
Las variables y constantes declaradas en el ámbito global son accesibles en cualquier parte del código, tanto dentro como fuera de funciones y bloques.

**Ámbito local**
El ámbito local se refiere a variables y constantes que solo pueden utilizarse en una parte concreta del código, como un bloque o una función. Dentro del ámbito local podemos distinguir:

- **Ámbito de función**: la variable o constante solo puede utilizarse dentro de la función en la que se ha declarado.
- **Ámbito de bloque**: la variable o constante solo puede utilizarse dentro del bloque en el que se ha declarado, como los utilizados en `if`, `for`, `while`, etc.

### 3.2. Declaración de variables y constantes

Tanto las variables como las constantes son referencias que se hacen dentro de un programa a posiciones de memoria que van a almacenar datos.

En JavaScript, las constantes se declaran utilizando la palabra reservada `const`.

```js
const anio = 2024;
```

Las variables se declaran anteponiendo `var` o `let`.

```js
var saludo = "Buenos días";
let edad = 20;
```

Aunque `var` y `let` permiten declarar variables, existen diferencias importantes entre ambas formas de declaración.

#### Diferencias entre var y let

Las principales diferencias entre `var` y `let` se encuentran en el **ámbito**, el **uso antes de la declaración** y la **redeclaración**.

**Ámbito**

Fuera de cualquier función o bloque, tanto `var` como `let` declaran variables globales (ámbito global).

Dentro de una función, ambas quedan limitadas a esa función (variables locales con ámbito de función).

La diferencia principal aparece dentro de bloques como `if`, `for` o `while`: `var` no tiene ámbito de bloque, mientras que `let` sí.

Si estos bloques se encuentran en el nivel principal del script, una variable declarada con `var` tendrá ámbito global, mientras que una variable declarada con `let` tendrá ámbito de bloque.

Si el bloque se encuentra dentro de una función, una variable declarada con `var` tendrá ámbito de función, mientras que una declarada con `let` seguirá teniendo ámbito de bloque.

**Uso antes de la declaración**

Una variable declarada con `var` puede ser referenciada antes de la línea en la que aparece su declaración. En ese momento su valor será `undefined`.

```js
console.log(numero); // undefined
var numero = 10;
```

Con `let` no es posible utilizar la variable antes de su declaración:

```js
console.log(numero); // Error
let numero = 10;
```

**Redeclaración**

Con `var` se puede volver a declarar una variable con el mismo nombre dentro del mismo ámbito:

```js
var nombre = "Ana";
var nombre = "Luis"; // Correcto
```

Con `let` no se puede volver a declarar una variable con el mismo nombre dentro del mismo ámbito:

```js
let nombre = "Ana";
let nombre = "Luis"; // Error
```

Esto no debe confundirse con reasignar un valor. Una variable declarada con `let` sí puede cambiar posteriormente de valor:

```js
let nombre = "Ana";
nombre = "Luis"; // Correcto
```

> **Importante**
> Las constantes declaradas con `const` tienen, al igual que las variables declaradas con `let`, ámbito de bloque. Además, una constante debe inicializarse en el momento de su declaración y no puede ser reasignada posteriormente.

> **Recomendación:** en JavaScript moderno se utiliza preferentemente `const` para valores que no vayan a ser reasignados y `let` para variables cuyo valor pueda cambiar. El uso de `var` se desaconseja generalmente, salvo en código antiguo o situaciones específicas. También conviene evitar, siempre que sea posible, el uso innecesario de variables globales.

### 3.3. Tipos de datos

JavaScript es un lenguaje de **tipado dinámico**, lo que significa que una variable puede contener valores de distintos tipos a lo largo de la ejecución del programa.

Como consecuencia, al declarar una variable no es necesario indicar previamente el tipo de dato que va a almacenar. El tipo viene determinado en cada momento por el valor que tenga asignado.

En JavaScript podemos distinguir dos grandes grupos de datos: **tipos primitivos** y **objetos**.

#### 1. Tipos primitivos

Son los tipos de datos más básicos y no tienen propiedades ni métodos. Los tipos primitivos en JavaScript son:

- `string`: Representa cadenas de texto. Ejemplo: `"Hola"` o `'Mundo'`.
- `number`: Representa números, tanto enteros como decimales. Ejemplo: `42`, `3.14`.
- `bigint`: Para representar números enteros muy grandes (más allá del límite de `number`). Ejemplo: `1234567890123456789012345678901234567890n`.
- `boolean`: Representa valores lógicos: `true` o `false`.
- `undefined`: Representa una variable que ha sido declarada pero no tiene un valor asignado.
- `null`: Representa la ausencia intencional de un valor. Es un objeto especial.
- `symbol`: Representa un valor único (JavaScript garantiza que será único). Se utiliza principalmente para crear claves únicas en objetos y evitar conflictos entre propiedades.

#### 2. Objetos

Los objetos permiten agrupar distintos datos relacionados entre sí y también funciones que trabajan con esos datos. Los datos se almacenan en **propiedades** y las funciones asociadas al objeto se denominan **métodos**.

En JavaScript, las funciones también son objetos.

Algunos tipos de datos de objeto son:

- `Object`: Es la base de todos los objetos. Puedes crear tus propios objetos con propiedades y métodos.
- `Array`: Es un tipo especial de objeto utilizado para almacenar listas ordenadas de valores.
- `Function`: También es un objeto en JavaScript. Las funciones son bloques de código reutilizables.

Además están `Date`, `RegExp`, `Map`, `Set`, `WeakMap` y `WeakSet`.

#### Variables, constantes y objetos

Cuando se trabaja con tipos primitivos, una constante declarada con `const` no puede recibir posteriormente un nuevo valor.

```js
const edad = 20;
edad = 21; // Error
```

En cambio, una variable declarada con `let` sí puede cambiar su valor durante la ejecución del programa.

```js
let edad = 20;
edad = 21; // Correcto
```

Con los objetos el comportamiento es diferente. Cuando una variable o constante contiene un objeto, lo que se almacena en el identificador es una **referencia** al objeto.

Si el objeto se declara mediante `const`, esa referencia no puede cambiar, pero **sí puede modificarse el contenido del objeto**.

Por ejemplo, un array declarado con `const` puede modificar sus elementos e incluso cambiar su tamaño:

```js
const numeros = [10, 20, 30];
numeros[0] = 50;    // Correcto
numeros.push(40);   // Correcto
```

Sin embargo, no se puede hacer que la constante pase a referenciar otro objeto:

```js
numeros = [1, 2, 3]; // Error
```

Si el objeto se declara mediante `let`, además de poder modificar su contenido, también se puede hacer que la variable pase a referenciar otro objeto:

```js
let numeros = [10, 20];
numeros = [30, 40]; // Correcto
```

En la siguiente unidad se profundizará en este comportamiento.

#### Tipos de datos primitivos (detalle)

Antes de nada hay que tener en cuenta que en JavaScript **no se declaran el tipo de las variables**, simplemente se les asigna o no un valor.

```js
var nombre = "pepe";
```

**Undefined**

Significa que no está definido. Esto es cuando al declarar una variable no se le ha asignado valor:

```js
let nombre;
```

También se puede conseguir que una variable quede sin tipo asignándole `undefined`.

```js
let nombre = undefined;
```

**Null**

El significado de este tipo depende del lenguaje de programación, pero en muchos casos, incluido en JavaScript, significa valor nulo.

```js
var resultado = null;
```

Además, al evaluar con `Boolean` una variable que tenga este valor, el resultado será `false`.

**Boolean**

Una variable booleana solamente puede tener dos valores, `true` (verdadero) o `false` (falso).

```js
var encontrado = true;
```

**String**

Este tipo de dato se emplea para almacenar una cadena de caracteres.

```js
let nombre = "pepe";
```

Una cadena de caracteres puede declararse con comillas dobles (`"`), comillas simples (`'`) y comillas invertidas (`` ` ``).

Con las comillas invertidas podemos utilizar expresiones `${}` cuya evaluación será lo que se incluya en la cadena:

```js
var apellidos = "abad montes";
var nombre = `pepe ${apellidos}`;
```

Para concatenar cadenas se emplea el símbolo `+`:

```js
var nombre = "pepe" + " abad " + "montes";
```

Hay caracteres especiales que no se pueden asignar ya que dentro de las cadenas tienen una función concreta, por lo que si queremos que se asignen como caracteres imprimibles debemos **"escaparlos"**, es decir, que no funcionen como caracteres especiales de cadenas de caracteres sino como caracteres imprimibles o normales.

Podemos expresar caracteres UNICODE utilizando `\u{<código_hexadecimal>}`.

```js
console.log("\u{058d}");
```

**Number**

Es un tipo numérico y puede ser un número entero o real. El carácter separador de decimales de los números reales es el punto.

```js
var n = 5;
var m = 1.5; // Número real
```

Además podemos representar números con exponente (10^n) utilizando la letra `e`.

```js
let t = 23e4;   // Esto equivale a 230000
let u = 23e-4;  // Esto equivale a 0,0023
```

También podemos expresar números en binario, octal y hexadecimal anteponiendo al número respectivamente `0b`, `0o` y `0x`.

```js
dato = 0b10010;
```

Valores especiales de `Number`:

- `NaN`: valor especial de tipo `number` que indica que una operación no ha producido un número válido.
- `Infinity`: valor especial de tipo `number` que representa infinito, por ejemplo `1 / 0`.

**BigInt**

Se utiliza para representar números muy grandes. Los números que puede manejar de tipo `number` están entre `Number.MAX_VALUE` y `Number.MIN_VALUE`.

Con `Number.MAX_SAFE_INTEGER` y `Number.MIN_SAFE_INTEGER` se puede saber el límite de los números que pueden representar correctamente.

Para indicar que se quiere utilizar `BigInt` el número debe finalizar en `n`.

```js
var grande = 1234567891231225024564n;
```

**Operador typeof**

Para finalizar, el operador `typeof` sirve para obtener el tipo de un dato.

```js
console.log(typeof(42)); // Devuelve number
```

### 3.4. Conversión de tipos

En JavaScript es posible convertir un valor de un tipo de dato a otro. Esta conversión puede realizarse de dos formas:

- **Conversión implícita o automática**: JavaScript realiza la conversión automáticamente según el contexto.
- **Conversión explícita**: el programador indica expresamente el tipo al que quiere convertir el valor.

#### Conversión automática de tipos

JavaScript puede convertir automáticamente un valor de un tipo a otro cuando una operación lo requiere. Este comportamiento se denomina también **coerción de tipos**.

**Conversión a String**

Cuando se utiliza una cadena junto con otro valor mediante el operador `+`, JavaScript convierte el otro valor en una cadena y realiza una concatenación.

```js
let result = 'La suma es: ' + 5; // "La suma es: 5"
```

Otro ejemplo:

```js
let resultado = "10" + 2; // "102"
```

**Conversión a Número**

En determinadas operaciones aritméticas, JavaScript intenta convertir los operandos a valores numéricos.

```js
let num = '10' - 2; // 8 (el string '10' se convierte a número)
```

Para operaciones como `+`, si uno de los operandos es un string, se concatenan en lugar de sumarse:

```js
let result = '10' + 2; // "102" (se concatena porque uno de los valores es string)
```

Si una cadena no puede convertirse en un número válido, el resultado será `NaN` (Not a Number).

```js
let resultado = "hola" * 4; // NaN
```

Los valores booleanos también pueden convertirse automáticamente en números:

- `true` se convierte en `1`.
- `false` se convierte en `0`.

```js
let resultado = true + 5; // 6
```

El valor `null` se convierte en `0` cuando se utiliza en un contexto numérico:

```js
let resultado = 4 * null; // 0
```

Sin embargo, si se concatena con una cadena, se convierte en el texto `"null"`:

```js
let resultado = "hola" + null; // "holanull"
```

**Conversión a Booleano**

Cuando JavaScript necesita evaluar un valor como verdadero o falso, realiza una conversión automática a `boolean`.

Los siguientes valores se consideran **falsy**, es decir, se convierten en `false`:

- `false`
- `0`
- `""` (cadena vacía)
- `null`
- `undefined`
- `NaN`

**Valores truthy**: cualquier otro valor que no esté en la lista anterior.

```js
if (0) {
    console.log('Esto no se ejecuta porque 0 es falsy.');
}
if ('hello') {
    console.log('Esto se ejecuta porque una cadena no vacía es truthy.');
}
```

**Conversión implícita con comparaciones**

Las comparaciones en JavaScript también pueden desencadenar conversiones automáticas de tipos. Los operadores de comparación como `==` realizan conversión de tipos cuando los operandos son de diferentes tipos.

```js
5 == '5'; // true (el string '5' se convierte a número para hacer la comparación)
```

Para evitar la conversión automática, usa el operador de comparación estricta `===`:

```js
5 === '5'; // false (no hay conversión de tipos, se comparan tal como son)
```

#### Conversión explícita

También es posible realizar las conversiones de forma explícita, indicando al programa el tipo de dato que se desea obtener.

`Number()`: convierte un valor a número. El valor puede ser un número entero o decimal.

```js
Number('5'); // 5
```

`parseInt()`: convierte un valor a número entero. Si el valor es un número real, solo convierte la parte entera.

```js
console.log(parseInt("10.5")); // Resultado: 10
console.log(Number("10.5"));  // Resultado: 10.5
```

`parseFloat()`: convierte una cadena en un número decimal:

```js
parseFloat("10.5"); // 10.5
```

La principal diferencia entre `Number()` y `parseInt()` / `parseFloat()` es que `Number()` intenta convertir el valor completo, mientras que `parseInt()` y `parseFloat()` pueden convertir la parte numérica situada al comienzo de una cadena.

```js
Number("10.5abc");     // NaN
parseFloat("10.5abc"); // 10.5
Number("10abc");       // NaN
parseInt("10abc");     // 10
```

`String()`: convierte un valor a string.

```js
String(5); // "5"
```

`Boolean()`: convierte un valor a booleano.

```js
Boolean(1); // true
```

## 4. Entrada y salida del navegador

### 4.1. Mensajes por consola

En JavaScript, puedes utilizar diferentes métodos del objeto `console` para imprimir mensajes o información en la consola del navegador o en un entorno de desarrollo como Node.js. A continuación se muestran algunos de los métodos más utilizados del objeto `console`.

**console.log()**

Es el método más utilizado para imprimir mensajes informativos. Se puede usar para depurar, mostrar resultados, valores de variables, etc.

```js
console.log("Mensaje informativo");
console.log(42); // Número
console.log({nombre: "Juan", edad: 30}); // Objeto
```

**console.error()**

Imprime un mensaje de error. Se utiliza para mostrar errores en el código, fallos en solicitudes de red, entre otros.

```js
console.error("Este es un mensaje de error");
```

**console.warn()**

Muestra una advertencia. Es útil para señalar potenciales problemas en el código que no son errores, pero podrían generar comportamientos inesperados.

```js
console.warn("Advertencia: El valor está vacío");
```

**console.info()**

Imprime información, similar a `console.log()`. Aunque en muchos navegadores se comporta igual, está pensado específicamente para mensajes informativos.

```js
console.info("Esto es un mensaje informativo");
```

**console.debug()**

Muestra mensajes de depuración, aunque en algunos entornos se comporta igual que `console.log()`. En ciertos navegadores, estos mensajes pueden no mostrarse a menos que la consola esté configurada en modo "depuración".

```js
console.debug("Mensaje para depurar");
```

La diferencia principal entre `log`, `error`, `warn`, `info` y `debug` no está en si muestran o no información, sino en cómo lo clasifica y presenta la consola. El navegador puede mostrarlos con iconos, colores o estilos distintos, y además permite filtrar por nivel. Por ejemplo, puedes indicar que solo quieres ver errores y advertencias.

**console.table()**

Imprime datos tabulados, ideal para visualizar arrays u objetos de una manera estructurada en forma de tabla.

```js
let usuarios = [
    {nombre: "Juan", edad: 30},
    {nombre: "Ana", edad: 25}
];
console.table(usuarios);
```

### 4.2. Ventanas de diálogo modales del navegador

Una **ventana de diálogo modal** es aquella que requiere la interacción del usuario antes de permitir continuar con la ejecución normal del programa o de la interfaz.

Los navegadores disponen de tres ventanas de diálogo modales que permiten introducir o mostrar información.

Para mostrar estas ventanas es necesario ejecutar el método adecuado del objeto `window`, aunque no es necesario, en este caso, anteponer `window.`.

**Alerta**

Es una ventana que se utiliza para mostrar un aviso al usuario.

```js
alert("Ha introducido mal el correo electrónico");
```

**Entrada texto**

Es una ventana que se emplea para que el usuario introduzca una cadena de caracteres.

```js
let nombre = prompt("Introduzca su nombre");
let edad = prompt("Introduzca su edad", "21");
```

El método `prompt()` devuelve una cadena de caracteres. Si el usuario cancela la ventana, devuelve `null`.

**Confirmación**

Es una ventana que muestra dos botones de forma que el usuario puede confirmar algo. El dato resultante es de tipo booleano.

```js
let con = confirm("¿Desea desplegar el panel?");
if (con) {
    // ...
}
```

## 5. Operadores

### 5.1. Operadores de asignación

Mediante la asignación podemos hacer que una variable tome un valor.

- Asignación simple: `=`
- Asignación compuesta: `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, `<<=`, `>>=`, `>>>=`, `&=`, `^=`, `|=`

### 5.2. Operadores de comparación

Estos operadores se emplean para comparar dos valores. El resultado de dicha comparación será un booleano (`true` o `false`).

**Los comparadores `==` y `!=` (comparación no estricta)**

- Solo compara los valores, no los tipos. JavaScript hará conversión de tipos implícita si es necesario.
- Ejemplo: `5 == '5'` devolverá `true` porque convierte el string `'5'` a número antes de comparar.

**Los comparadores `===` y `!==` (comparación estricta)**

- Compara tanto el valor como el tipo de dato. No realiza conversión automática de tipos.
- Ejemplo: `5 === '5'` devolverá `false` porque uno es un número y el otro es un string.

**Operadores relacionales (`>`, `<`, `>=`, `<=`)**

- Comparan dos valores numéricos o strings (según su orden en el alfabeto).
- También pueden hacer comparaciones entre otros tipos de datos, pero generalmente se utilizan con números.

### 5.3. Operadores aritméticos

Suma (`+`), resta (`-`), multiplicación (`*`), división (`/`), módulo o resto (`%`), exponenciación (`**`), incremento (`++`) y decremento (`--`).

### 5.4. Operadores bit a bit

**¿Cómo funcionan los operadores binarios en JavaScript?**

- **Conversión a binario**: Cuando se utilizan operadores binarios (o bit a bit) en JavaScript, el lenguaje convierte internamente los operandos a su representación binaria. Los números se manejan en formato de 32 bits con signo, lo que significa que se representan como enteros de 32 bits (incluso si se proporcionan números decimales).
- **Operación bit a bit**: Después de la conversión a binario, JavaScript realiza la operación binaria directamente sobre estos bits. Dependiendo del operador binario que uses (`&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`), se trabaja bit por bit en los números.
- **Conversión de nuevo a decimal**: Una vez completada la operación, el resultado en binario se convierte de nuevo a su representación decimal antes de devolver el valor final.

### 5.5. Operadores lógicos

Los operadores lógicos en JavaScript se utilizan para realizar evaluaciones lógicas que involucran condiciones. Su propósito principal es controlar el flujo de un programa, tomar decisiones basadas en el valor de expresiones booleanas y realizar operaciones condicionales.

Operadores: `&&` (AND), `||` (OR), `!` (NOT).

### 5.7. Operador condicional

El operador condicional o **operador ternario** en JavaScript es una forma abreviada de realizar evaluaciones condicionales, similar a un `if-else`, pero en una sola línea. Es muy útil cuando necesitas tomar una decisión rápida y devolver un valor u otro dependiendo de si una condición es verdadera o falsa.

**Sintaxis**

```js
condición ? expresión_si_verdadero : expresión_si_falso;
```

**Significado:**

- `condición`: Es la expresión que se evalúa. Si es `true`, se ejecuta la primera expresión; si es `false`, se ejecuta la segunda.
- `expresión_si_verdadero`: Se ejecuta si la condición es verdadera (`true`).
- `expresión_si_falso`: Se ejecuta si la condición es falsa (`false`).

**Ejemplo básico:**

```js
let edad = 18;
let mensaje = (edad >= 18) ? "Es mayor de edad" : "Es menor de edad";
console.log(mensaje); // "Es mayor de edad"

// Aquí, la variable mensaje tomará el valor "Es mayor de edad" si edad >= 18 es true,
// y "Es menor de edad" si es false.
```

## 6. Estructuras de control

Las estructuras de control permiten modificar el flujo normal de ejecución de un programa. Mediante ellas es posible tomar decisiones, repetir instrucciones o ejecutar distintos bloques de código en función de determinadas condiciones.

Entre las estructuras de control más habituales se encuentran las estructuras condicionales y las estructuras repetitivas.

### 6.1. Estructura if

Se utiliza para tomar decisiones y ejecutar código basándose en una condición booleana (verdadera o falsa).

**Sintaxis básica**

```js
if (condición) {
    // Código a ejecutar si la condición es verdadera
}
```

**Estructura con else:**

Si se quiere ejecutar un bloque de código alternativo cuando la condición es falsa, se puede usar `else`.

```js
if (condición) {
    // Código si la condición es verdadera
} else {
    // Código si la condición es falsa
}
```

**Estructura con else if:**

Se pueden agregar múltiples condiciones con `else if` para manejar más de dos escenarios.

```js
if (condición1) {
    // Código si la condición1 es verdadera
} else if (condición2) {
    // Código si la condición2 es verdadera
} else {
    // Código si ninguna condición es verdadera
}
```

### 6.2. Estructura switch

Se utiliza cuando tienes múltiples posibles valores para una expresión y quieres ejecutar diferentes bloques de código dependiendo de cada valor. Es una alternativa al uso repetido de `if...else if`.

**Sintaxis básica:**

```js
switch (expresión) {
    case valor1:
        // Código a ejecutar si expresión === valor1
        break;
    case valor2:
        // Código a ejecutar si expresión === valor2
        break;
    default:
        // Código a ejecutar si no coincide con ningún valor
}
```

**Explicación:**

- `expresión`: Es el valor que se evalúa una vez.
- `case valorX`: Compara la expresión con `valorX` mediante una comparación estricta (`===`). Si coinciden, se ejecuta el bloque de código asociado. Además, se pueden mezclar diferentes tipos de datos, como números y cadenas.
- `break`: Detiene la ejecución del `switch` y evita que se ejecuten otros casos. Si no se coloca, los casos siguientes también se ejecutarán (comportamiento conocido como **fall-through**).
- `default`: Es un caso opcional que se ejecuta si ninguno de los `case` coincide con la expresión.

### 6.3. Estructura for

Es un bucle que se utiliza para repetir un bloque de código un número determinado de veces. Es muy útil cuando conoces de antemano cuántas veces deseas que se ejecute el ciclo.

**Sintaxis básica**

```js
for (inicialización; condición; actualización) {
    // Código a ejecutar en cada iteración
}
```

**Explicación**

- **Inicialización**: Se ejecuta una vez al principio del bucle. Se suele usar para declarar e inicializar una variable de control.
- **Condición**: Se evalúa antes de cada iteración. Si es `true`, el bucle se ejecuta; si es `false`, el bucle se detiene.
- **Actualización**: Se ejecuta al final de cada iteración. Generalmente se usa para incrementar o modificar la variable de control.

### 6.4. Estructura while

Es un bucle que repite un bloque de código mientras una condición sea verdadera. Se evalúa la condición antes de cada iteración, y si es `true`, el código dentro del bucle se ejecuta; si es `false`, el bucle se detiene.

**Sintaxis básica**

```js
while (condición) {
    // Código a ejecutar mientras la condición sea verdadera
}
```

**Explicación:**

- `condición`: Es una expresión booleana (que devuelve `true` o `false`). Mientras sea `true`, el bucle continuará ejecutándose.
- Si la condición es `false` desde el principio, el bloque de código no se ejecuta ni una sola vez.

### 6.5. Estructura do..while

Es un bucle similar a `while`, pero con una diferencia clave: **siempre se ejecuta al menos una vez**, ya que la condición se evalúa después de ejecutar el bloque de código.

**Sintaxis básica**

```js
do {
    // Código a ejecutar
} while (condición);
```

**Explicación:**

- El bloque de código se ejecuta primero, y luego la condición es evaluada.
- Si la condición es `true`, el bucle se repetirá.
- Si la condición es `false`, el bucle se detendrá después de la primera iteración.

### 6.6. Instrucciones de salto

Existen instrucciones que permiten cambiar el flujo de ejecución del código de un punto a otro no consecutivo. A esto se le llama **"salto"**.

#### Instrucción break

Se utiliza para terminar la ejecución de un bucle (`for`, `while` o `do...while`) o de una estructura de control `switch` (ya lo hemos visto) de manera anticipada. Al encontrarse con `break`, el flujo de ejecución salta fuera del bloque correspondiente, y el programa continúa con el siguiente código después del bucle o del `switch`.

Cuando se usa dentro de un bucle, `break` finaliza inmediatamente la ejecución del bucle y el programa continúa con la primera instrucción situada después del mismo.

En caso de bucles anidados, `break` finaliza únicamente el bucle más interno que lo contiene. El bucle exterior continúa su ejecución normalmente.

> **Regla**
> Un `break` sale del bucle más próximo que lo contiene.

**Ejemplo en un bucle**

```js
for (let i = 0; i < 10; i++) {
    if (i === 5) {
        break; // Sale del bucle cuando i es igual a 5
    }
    console.log(i);
}
```

En este caso, el bucle imprimirá los números del 0 al 4. Cuando llegue al 5 se detendrá el bucle saltando a la línea siguiente de la llave `}` que finaliza el `for`.

#### Instrucción continue

Se utiliza dentro de bucles (`for`, `while` y `do...while`) para omitir la iteración actual y pasar a la siguiente. Cuando se encuentra con `continue`, el flujo de ejecución salta directamente a la siguiente iteración del bucle, ignorando cualquier código que se encuentre después de `continue` en la iteración actual.

**Uso de continue:**

Dentro de bucles: Sirve para saltar a la siguiente iteración sin finalizar el bucle por completo.

**Ejemplo**

```js
for (let i = 0; i < 5; i++) {
    if (i === 2) {
        continue; // Salta la iteración cuando i es igual a 2
    }
    console.log(i);
}
```

En este ejemplo, el bucle imprimirá 0, 1, 3 y 4. Cuando `i` es 2, la instrucción `continue` se ejecuta, y el resto del código en esa iteración se omite, pasando directamente a la siguiente iteración.

#### Etiquetado de bucles (labeled)

Se pueden etiquetar bucles o bloques de código con un nombre, lo que facilita la identificación y el control del flujo de ejecución, de forma que podremos saltar un bloque de código concreto.

**Sintaxis básica**

```js
labelName:
for (let i = 0; i < 5; i++) {
    // Código
}
```

Por ejemplo, podemos tener un bucle con un nombre y cuando queramos salir de ese bucle, utilizaremos `break` junto con el nombre del bucle. Se puede usar con bucles anidados para especificar a cuál bucle se desea saltar o continuar.

**Ejemplo**

```js
outerLoop:
for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
        if (i === 1 && j === 1) {
            break outerLoop; // Sale del bucle externo
        }
        console.log(`i: ${i}, j: ${j}`);
    }
}
// El flujo del programa continúa por aquí
```

En este ejemplo:

- Hay un bucle externo etiquetado como `outerLoop`.
- Cuando `i` es 1 y `j` es 1, se ejecuta `break outerLoop`, lo que provoca que se salga del bucle externo, no solo del interno.

## 7. Herramientas para la programación, prueba y documentación

Para desarrollar código JavaScript se pueden utilizar distintas herramientas que facilitan la escritura, ejecución, prueba, depuración y consulta de documentación.

**Editor de código**: Visual Studio Code permite escribir y organizar el código JavaScript, además de ofrecer ayudas como resaltado de sintaxis, autocompletado y detección de errores.

**Herramientas de desarrollo del navegador**: los navegadores incorporan herramientas que permiten ejecutar código, consultar mensajes de la consola, inspeccionar elementos y analizar la ejecución del programa.

- **Prueba del código**: el código JavaScript puede ejecutarse directamente en el navegador para comprobar su funcionamiento y verificar que los resultados obtenidos son los esperados.
- **Depuración mediante la consola**: se pueden utilizar instrucciones como `console.log()` para mostrar mensajes o valores de variables durante la ejecución. Esto permite comprobar qué partes del código se están ejecutando y localizar errores.

```js
let numero = 10;
console.log("Valor inicial:", numero);
numero = numero + 5;
console.log("Valor después de la operación:", numero);
```

- **Puntos de interrupción**: las herramientas de desarrollo del navegador permiten detener temporalmente la ejecución del programa en una determinada línea. Mientras la ejecución está detenida se pueden consultar los valores de las variables y avanzar paso a paso por el código.

**Documentación**: para consultar la sintaxis, características y funcionamiento de JavaScript se pueden utilizar fuentes de documentación como [MDN Web Docs](https://developer.mozilla.org).
