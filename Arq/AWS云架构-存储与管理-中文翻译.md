# AWS 云架构 - 笔记与总结

---

## 1. 管理

### 1.1 交互方式
- **AWS 控制台**：AWS 的 Web 界面。
- **AWS CLI**：AWS 的命令行界面。
- **AWS SDK**：在系统中进行 AWS 命令行交互的集成包。
- **REST API**：通过调用 AWS API 进行交互。

### 1.2 管理类型

#### 自管理（Self-managed）
- **定义**：用户负责服务器和操作系统的管理、配置、扩展和维护。
- **控制**：对基础设施有更大的控制权和自定义能力。
  - **用户可选择**：CPU、内存、网络策略、IAM、启动、操作系统、补丁和更新。
  - **供应商管理**：物理基础设施。
- **资源调配**：需要用户进行调配和配置。
- **部署时间**：需要较长的等待时间才能使用。

#### 完全托管（Fully managed）
- **定义**：由供应商负责操作系统和底层硬件的管理。
- **控制**：对基础设施具有中等程度的控制和自定义能力。
  - **用户可选择**：CPU、内存、网络策略、IAM 和启动需求。
  - **供应商管理**：基础设施、操作系统、补丁和更新。
- **资源调配**：需要进行调配，由供应商进行配置。
- **部署时间**：等待使用的时间较短。

#### 无服务器（Serverless）
- **定义**：无需调配、配置或管理。由供应商负责、配置和管理该服务。
- **控制**：对基础设施没有任何控制或自定义能力。
  - **用户可配置**：网络策略、IAM 和启动。
  - **供应商管理**：全部基础设施、CPU、内存、操作系统、补丁和更新。
- **资源调配**：已完成调配和配置 $\rightarrow$ **开箱即用**。

## 2. 存储

### 2.1 存储类型

#### A. 块存储（Block Storage）
*示例：Amazon EBS*

- **特点**：
  - 硬盘驱动器（HDD）或固态驱动器（SSD）。
  - 划分为多个块。
- **卷类型**：
  - **通用型 SSD（gp2 / gp3）**：适用于均衡的工作负载。
  - **预置 IOPS SSD（io1 / io2）**：
    - **io1 / io2**：为关键数据库提供持续性能和低延迟。
    - **io2 Block Express**：超高性能。
  - **吞吐量优化型 HDD（st1）**：适用于频繁访问和大数据量存储。
  - **冷 HDD（sc1）**：适用于访问不频繁的数据，经济实惠。

#### B. 文件存储（File Storage）
*示例：Amazon EFS、FSx*

- **Amazon EFS（弹性文件系统）**：
  - 完全托管的 NFS 文件系统。
  - 可扩展，并可在多个 EC2 实例之间共享。
- **Amazon FSx**：
  - **FSx for Windows File Server**：原生 Windows 文件系统（SMB）。
  - **FSx for Lustre**：用于高性能计算（HPC）和机器学习。

#### C. 对象存储（Object Storage）
*示例：Amazon S3*

- **关键概念**：
  - **存储桶（Buckets）**：用于存放对象的容器。
  - **对象（Objetos）**：文件及其关联的元数据。
- **S3 存储类**：
  - **S3 Standard（标准）**：用于频繁访问的数据，具有高可用性和持久性。
  - **S3 Intelligent-Tiering（智能分层）**：根据访问模式在层级之间自动移动对象，以优化成本。
  - **S3 Standard-IA（不频繁访问）**：用于访问频率较低但需要即时访问的数据。
  - **S3 One Zone-IA（单区不频繁访问）**：适用于在单个可用区中不经常访问的非关键数据，成本更低。
  - **S3 Glacier Flexible Retrieval（灵活检索）**：低成本数据归档，恢复时间从几分钟到几小时不等。
  - **S3 Glacier Deep Archive（深度归档）**：用于长期保留的最低成本存储（12 小时内恢复）。

## 3. 迁移与备份策略

- **AWS Backup**：用于自动化和管理所有 AWS 服务备份的集中式服务。
- **AWS DataSync**：在线数据传输服务，可简化并加速数据迁移。
- **AWS Snow 系列**：
  - **Snowcone**：用于边缘环境中数据传输的便携式设备。
  - **Snowball**：通过安全设备进行 TB/PB 级的大规模数据传输。
  - **Snowmobile**：在安全运输容器中进行的 EB 级传输。
