Dos galerías,
dos técnicas

La misma idea —una colección de imágenes de distintos tamaños— resuelta dos veces: primero con Flexbox y después con CSS Grid. Ambas galerías son independientes y se reorganizan para escritorio, tablet y móvil.

  • 24imágenes colocadas
  • 2galerías independientes
  • 3tamaños de pantalla
01

Galería Flexbox

Construida con display: flex, flex-wrap y flex-basis. Cada fila suma el 100 % del ancho y las tres imágenes destacadas ocupan el doble de espacio que el resto.

02

Galería CSS Grid

Construida con display: grid y una retícula de cuatro columnas. Las imágenes grandes se expanden con grid-column: span y grid-row: span, ocupando varias celdas a la vez.

¿Cuál ha sido más práctica?

Para este diseño, CSS Grid: permite pensar la galería como una retícula y hacer que una imagen ocupe varias celdas con una sola línea (grid-column: span 2). Con Flexbox hay que calcular los flex-basis de cada fila para que sumen el 100 %, algo más laborioso cuando el diseño tiene dos dimensiones. La explicación completa está comentada al final de css/styles.css.
